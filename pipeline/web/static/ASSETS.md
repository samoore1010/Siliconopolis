# Village assets and licenses

Everything the village renders is generated at runtime by `village.js`; there are no image, sprite
sheet or tileset files in this directory.

| Asset | Source | License |
|---|---|---|
| Character sprite (12x16 grid in `BODY` / `BODY_TYPING`), recolored per agent | drawn by hand for this project as character-grid strings | original work, same license as the repository |
| Desks, monitors, the Brain, outbox, reject bin, floor tiles, path | procedural Canvas drawing in `village.js` | original work, same license as the repository |
| Product tokens (paper sheets) and state overlays (stop sign, "!", clock, bubbles) | procedural Canvas drawing | original work |
| Fonts | system UI / system monospace font stack | none shipped |
| Palette | `PAL` in `village.js` and CSS variables in `village.css` | original |

Nothing was copied from Pixel Agents, pixtuoid, Claude Office, or any paid or third-party tileset.
If you add artwork later, record its source and license here before shipping it.
